Security model

File integrity
SHA-256 in browser and on server; mismatches are refused
File storage
Inside PostgreSQL, re-hashed on every download
Submission receipts
HS256-signed JWT over data hash + file hashes
Locking
Submitted ideas can't be edited; only a change request reopens them
Blind review
Evaluators never see Omang, age or contact details, and must declare conflicts first
Access control
Five roles; every API route checks the role, not just the page
Personal data
Data Protection Act 2024: consent recorded, Omang masked, self-service export
Audit log
Every submission, assignment, declaration, score, decision, download, export and role change
