> The platform

One range for the whole journey, from first idea to award.

Train and get measured like a national competition, then apply through CEDA's fair, auditable pipeline. Six modules, one login.

RANGE
Challenge engine

Short, scored tasks across six tracks. Quizzes are marked instantly; evidence tasks are verified by CEDA staff. First solves earn a bonus.

Enter the Range
INDEX
Innovator Index

A 0 to 1000 rating built from panel scores, pipeline progress, challenges and events. Every point is explained, and it never decides an award on its own.

See the league
CALLS
Guided submission

One form per call, with eligibility checked up front. Every version is sealed with SHA-256 and a signed receipt.

Browse open calls
PANEL
Blind, fair scoring

Conflict declared before an idea opens. Scores are normalised so harsh and generous judges count equally.

How scoring works
LIVE
Real-time tracking

A live tracker for every idea, notifications at each stage, and a pipeline board for CEDA.

See live tracking
TALENT
Talent directory

CEDA and partners find ranked, verified youth companies by sector, district and tier, with consent.

See the directory
